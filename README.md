# Maven-Toy-Sales
## Turning Raw Sales Data into Actionable Business Insights
In this project, I built an interactive dashboard to analyze sales performance for Maven Toys across multiple dimensions including product categories, store locations, and time.

The goal of this analysis was to answer key business questions such as:
- Which products generate the most revenue?
- Which store locations perform best?
- How does revenue change over time?
- Which product categories drive the highest number of orders?

### Dataset Overview
The dataset contains toy sales records across:
- 5 product categories
- 50 store locations
- Multiple cities and store types
- Time-based sales data

### Key Metrics at a Glance
- Total Orders: 829,000
- Total Revenue: $14.44M
- Total Profit: $4.01M
- Number of Stores: 50
- Product Categories: 5

### Key Insights
- Lego Bricks emerged as the highest revenue-generating product.
- Downtown stores outperformed other locations in total revenue.
- The Toys category contributed the largest share of overall revenue.
- Revenue trends over time reveal clear peaks and dips, indicating seasonality in toy sales.

### Dashboard Features
Interactive slicers for:
- Product Category
- Store Location
- Store City
- Store Name
- Date

Visual breakdown of:
- Revenue by product and category
- Orders by category
- Sales performance by location
- Revenue trends over time
